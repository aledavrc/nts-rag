Con ~--render~ el Markdown se ve con tablas, listas y negritas en la terminal.

~inspeccionar~ muestra la estructura del índice (colección, registros, dimensión
384, metadatos, tipos) y luego los vectores que activa la pregunta: similitud,
página, sección y las primeras componentes del embedding. Admite ~--json~ y
~--sin-vector~. Equivalente con make:
~make inspeccionar PREGUNTA="cadena de frío" K=2~.

* Demostrar el cambio: con rerank, sin rerank y sin LLM

El pipeline completo hace 3 llamadas al LLM: rerank → respuesta → verificación.
Se pueden quitar las dos últimas de forma independiente.

** Las tres variantes en la CLI

#+begin_src bash
P="¿Cuál es la composición de la vacuna antineumocócica?"

# 1) Pipeline completo: rerank + respuesta + verificación (3 llamadas)
.venv/bin/python -m nts_rag.cli consultar --json "$P" \
  | jq '{modo, paginas: [.fuentes[].pagina]}'

# 2) Sin rerank: respuesta + verificación (2 llamadas)
.venv/bin/python -m nts_rag.cli consultar --sin-rerank --json "$P" \
  | jq '{modo, paginas: [.fuentes[].pagina]}'

# 3) Sin LLM: solo recuperación híbrida + extracto verbatim (0 llamadas)
NTS_RAG_LLM_BASE_URL= .venv/bin/python -m nts_rag.cli consultar --json "$P" \
  | jq '{modo, paginas: [.fuentes[].pagina]}'
#+end_src

También con la variable de entorno en vez del flag:

#+begin_src bash
NTS_RAG_RERANK=false .venv/bin/python -m nts_rag.cli consultar "$P"
#+end_src

** Resultado real de las tres variantes

Medido con la pregunta del ejemplo:

| Variante              | ~modo~       | Páginas recuperadas       | Tiempo aprox. |
|-----------------------+-------------+---------------------------+---------------|
| con rerank            | ~llm~        | 24, 24, 24, 24, 24, 24    | ~6 s          |
| ~--sin-rerank~        | ~llm~        | 24, 37, 27, 25, 24, 48    | ~5 s          |
| sin LLM               | ~extractivo~ | 24, 37, 27, 25, 24, 48    | ~2 s          |

Cómo leerlo:

- El rerank reordena/filtra los candidatos: en este caso deja los 6 fragmentos
  de la página 24 y descarta ruido de otras páginas.
- Sin rerank el orden es el de la recuperación híbrida (vectorial + BM25), que es
  exactamente el mismo que usa el modo extractivo.
- ~modo~ te dice qué camino se tomó: ~llm~ (respuesta redactada) o
  ~extractivo~ (fragmento literal con cita). El extractivo empieza con
  "**Según la normativa cargada:**".
- El tiempo incluye cargar el modelo de embeddings (~1,5–2 s por proceso), por
  eso la diferencia entre las dos primeras variantes es menor de lo que sugiere
  el número de llamadas.

** Sin rerank ni verificación (1 sola llamada)

#+begin_src bash
NTS_RAG_RERANK=false NTS_RAG_VERIFY=false \
  .venv/bin/python -m nts_rag.cli consultar "$P"
#+end_src

El ~modo~ sigue siendo ~llm~, pero se pierde la comprobación de fidelidad: si el
modelo alucina, nadie lo detecta. Úsalo solo para comparar velocidad.

** Resumen de combinaciones

| Llamadas al LLM | Comando CLI                                                        | ~modo~       |
|-----------------+--------------------------------------------------------------------+--------------|
| 3               | ~consultar "$P"~                                                   | ~llm~        |
| 2               | ~consultar --sin-rerank "$P"~                                      | ~llm~        |
| 1               | ~NTS_RAG_RERANK=false NTS_RAG_VERIFY=false consultar "$P"~         | ~llm~        |
| 0               | ~NTS_RAG_LLM_BASE_URL= consultar "$P"~                             | ~extractivo~ |

Para el servidor, sustituye ~consultar "$P"~ por ~make serve~ y lanza la consulta
con ~curl~ (o usa ~NTS_RAG_*~ en el entorno de ~make serve~).

** Lote rápido contra la API

#+begin_src bash
for q in \
  "¿Cuál es la finalidad de la NTS 246?" \
  "¿Cuál es el esquema de vacunación de la Tdap en gestantes?" \
  "¿Cuánto tarda en aparecer la anafilaxia asociada a la DPT?"
do
  echo "== $q"
  curl -sS -X POST $API/consulta \
    -H "Content-Type: application/json" \
    -d "$(jq -nc --arg q "$q" '{pregunta: $q}')" \
    | jq -r '"\(.modo) | \(.tiempo_ms) ms\n\(.respuesta)\n"'
done
#+end_src

* Notas

- El puerto por defecto es el 8000; si está ocupado, arranca sin ~make~:
  ~.venv/bin/python -m nts_rag.cli servir --port 8011~.
- ~GET /v1/models~ solo existe para que clientes que sondean la API estilo OpenAI no ensucien el log; el servicio no implementa ~/v1/chat/completions~.
- La primera consulta puede tardar más: el modelo de embeddings se descarga una sola vez.
